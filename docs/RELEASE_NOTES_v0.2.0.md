# DeltaMuse Player v0.2.0

把 DeltaMuse 导出的**单声部 MIDI** 映射到《三角洲行动》口琴键位，按时序自动演奏。
使用说明见 [README](https://github.com/waitforhermione/DeltaMusePlayer#readme)。

---

## 变更

**紧急停止改为全局热键（F12 → F9）。**

- 快捷键 `F12` → **`F9`**。
- 改用系统级热键注册（`RegisterHotKey` + 专属消息窗口与线程），**切到游戏后依然能按**。
  窗口内快捷键只在自身是焦点时有反应，而真实用法正是「点播放 → 倒计时里切走」，
  所以原来的 F12 恰恰在最需要它的时刻是聋的。
- **不是**键盘钩子：没有 `WH_KEYBOARD_LL`、不注入进程、不装驱动、不轮询键盘状态。
- 可反复按；关窗时把 `F9` 还给系统；回调出错不会带崩进程。
- 注册失败（`F9` 被别的程序占用）时降级为「仅本窗口有效」并在界面写明，**不假装热键可用**。

**新增：只弹某一段。**

- 「演奏片段」填起止时间即可，格式 `mm:ss.mmm` / `1:23` / 秒数；终点留空表示到曲尾。
- **起点含、终点不含**；跨越终点的长音**截断在终点**（单音乐器必须在边界松开）。
- 片段内音符保持源文件时间轴，不平移到 0，方便对着谱子对号。
- 界面提供「从当前位置 / 前 30 秒 / 末 30 秒 / 终点 +30 秒」快捷填充与实时预览。
- 命令行对应 `--range 0:30-1:15`。

**M2：Windows 用户态真实键鼠输入。**

- `WindowsInputBackend`：`SendInput` 注入，键盘走扫描码（`KEYEVENTF_SCANCODE`），扫描码由 `MapVirtualKeyW` 取得。
- 安全闸门：默认 Preview、Real Input 需一次确认、倒计时 0/1/2/3/5/10s（默认 3）、
  **REAL INPUT ACTIVE** 横幅、只释放本程序按过的输入、异常路径 best-effort 释放。
- 全程 `asInvoker`，不自我提权。
- 诊断命令：`keymap` / `dryrun` / `send` / `hotkey` / `--diagnose`。

**修复三个真实 bug：**

1. 倒计时误用「停止按钮可用性」当取消信号，导致倒计时第一秒自我中止、派发 0 条 ——
   表现就是「倒计时一结束就立刻播放结束」。
2. 时序诊断把倒计时预滚当成抖动，均值 / p95 / 最大被抬到 3000ms 量级。
   现在「整体偏移（误差最小值）」与「抖动（扣偏后残差）」分开报告。
3. 反向片段（如 `--range 5-2`）会抛出未处理异常、退出码 `-1`；现在是干净的参数错误。

**文档：** README 精简为纯使用说明。

**关于热键按键触发：** 合成按键（`SendInput`）**不会**触发 `RegisterHotKey` 注册的系统热键，
所以「按 F9 真的能停」这件事在自动化测试里测不了。已验证的是：注册成功、
`WM_HOTKEY` 投递到本程序的消息窗口会被正确处理、关窗归还组合键。
请自己跑一次确认：

```
DeltaMusePlayer.exe hotkey
```

它会注册真实热键并等你按一下 `F9`，10 秒内按下即通过。

**关于 Notepad / 鼠标 / 游戏内：** 开发环境没有可靠的窗口焦点控制。
**「SendInput 被系统接受」不等于「目标窗口确实收到了字符」** ——
上游戏之前请先按 README 在记事本里自己验收一遍。
